.cn 域名权威 DNS 由谁提供？

① Top-20 .cn 权威 NS 提供商

图解 .cn 域名权威 DNS 由谁提供？
这是什么图？ 条形图列出解析 .cn 顶级域名的 前 20 个权威 NS(域名服务器)提供商，按覆盖 .cn 域名数量排序。 什么是权威 NS？ 当用户访问 xxx.cn 时，浏览器必须先问一个"权威 DNS 服务器" ——"这个域名在哪台机器上？"。权威 NS 是 .cn 域名体系的"电话本"。 Top 5 是谁？ 采样 500 个 NS 覆盖 121,554 个 .cn 域名。 ① "Other (com)" 111,415——未能精确识别的海外 NS 提供商； ② Aliyun 2,844——阿里云； ③ "Other (net)" 2,356； ④ "Other (cn)" 1,914； ⑤ Cloudflare 1,595。 观察： Cloudflare 等美国商用 DNS 即便在 .cn 域上仍占一席； 而绝大多数 .cn 域名托管在 .com 域的海外权威 NS 上，未能精确归属到某家运营商。 中国大陆籍 NS 份额仅 3.16%。 这在"主权指数 · DNS Sovereignty"打分 0.032， 是综合指数中的最短板之一(与 IXP 本地化并列)。

提供商 → 国家 的权威 DNS 桥接关系

② 提供商 → 国家 Sankey

图解 提供商 → 国家 的权威 DNS 桥接关系
这是什么图？ Sankey 桑基图——展示"NS 提供商 → 其归属国家"的流向，流宽代表 .cn 域名覆盖量。 怎么读？ 左侧是 NS 提供商(Aliyun、Cloudflare 等)， 右侧是国家(CN、US、DE……)。流线宽度直接对应该 NS 承载的 .cn 域名数。 核心发现？ · 中国大陆籍 NS 占 3.16%——主要是 Aliyun(CN)、DNSPod(CN)、华为云等； · 美国籍 NS 占 1.39%——主要 Cloudflare、GoDaddy、AWS Route53； · 大量流向"其他/未识别"(占比 >90%)——这是 DNS 数据可见性缺口， .cn 域名背后的 NS 记录大多挂在 .com/.net 上，无法从字面判断国籍。 启示？ .cn 顶级域在"行政上"属于中国大陆国家顶级域， 但其解析实际被多国 DNS 服务商分担——技术主权和行政主权并不完全一致。 改善方向？ 促进国产 DNS 服务商(阿里、腾讯、华为)市场份额； 结合 "双栈 DNS"(传统+DNSSEC) 提升安全。

.cn 权威 DNS 的国籍占比

③ 国籍占比

图解 .cn 权威 DNS 的国籍占比
这是什么图？ 饼图——按"NS 国籍"拆分 .cn 域名占比。 数据： 中国大陆籍 NS 约 3.16%，美国籍 1.39%，其他(欧盟+东南亚+未识别)占 90% 以上。 为什么"未识别"这么大？ 许多 NS 域名本身挂在 .com/.net 等通用顶级域， 无法从 NS 域名直接判断国籍；加上 Cloudflare/CDN NS 节点分布全球 200+ 城市， 本质上无国界。 更令人深思的是： 有一个"反向出海"的有趣现象——阿里 DNS 的 vip3.alidns.com、vip7.alidns.com 等中国大陆 NS 服务的顶级域名中， 大量是外国 .com/.net 域名，单个 NS 就覆盖 4,500+ 个非中国大陆域名—— 说明中国大陆 DNS 厂商(尤其阿里、腾讯)不仅服务国内，也承接相当多国际客户。 启示？ 中国大陆 DNS 自主率只有 3.16%(按 NS 国籍精确归属)， 未来增长点在于"中国大陆 DNS 服务国际化"，从"被依赖"转向"输出服务"。
