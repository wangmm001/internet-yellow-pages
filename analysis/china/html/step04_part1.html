中国前 20 大 AS 各控制多少 IP 地址？

① 起源前缀 · Treemap

图解 中国前 20 大 AS 各控制多少 IP 地址？
这是什么图？ Treemap(方块树状图)——每个方块代表一个中国 AS, 面积大小表示它起源(即"宣告拥有")的 BGP 前缀数量。 什么是"起源前缀"？ 路由表里每条前缀都必须由某个 AS"宣告"为自己的归属， 这就像在互联网地契上登记房产。方块越大，说明该 AS 占有的 IP 地址版图越广。 图中能看到什么？ 前 5 大起源者——AS9808(中国移动) 21,046 个、 AS4538(中国科技网) 10,327、AS56046/23910/56041 各几千个——几乎占据全图。 总计 5,211 个中国 AS 参与 BGP 路由起源。 解读方向： 如果把中国 IP 空间比作"国土"，这张图展示了主要"地主"； 少数几个最大方块就是中国互联网 IP 地址的"地产巨头"，它们一旦发生路由泄露或劫持， 影响面会非常大。

IPv4 与 IPv6 前缀如何分配？

② v4 vs v6 Split · Log-scale

图解 IPv4 与 IPv6 前缀如何分配？
这是什么图？ 两个对数条形图比较中国起源的 IPv4 前缀(71,967 个)和 IPv6 前缀(48,702 个)。 为什么要分开看？ IPv4 和 IPv6 是两套互相独立的 IP 地址系统： IPv4 是 1981 年定义的 32 位地址(约 43 亿个)，现已用尽；IPv6 是 128 位 (几乎无限)的下一代替代品。 中国的特殊情况？ v4 占 59%、v6 占 41%——v6 比例在全球领先。 原因是中国 IPv4 地址分配早期不足，政府强推 IPv6(《推进 IPv6 规模部署行动计划》 2017年起)，阿里、电信、移动都在大规模部署。 为什么用对数刻度？ 头部 AS 的前缀数比尾部多上千倍，线性刻度下尾部 几乎看不见；对数让每一格代表×10，一眼看清分布跨度。 启示？ 中国在 IPv6 部署上是全球领先者；这是难得一块"结构好"的指标。
