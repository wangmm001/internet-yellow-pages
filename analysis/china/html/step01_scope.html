中国区都有哪些“互联网行政区”？

① 中国区 AS 分层 · Sunburst

图解 中国区都有哪些“互联网行政区”？
这是什么图？ 旭日图把"中国区"所有自治系统(AS)按层级展开。 什么是 AS？ 互联网由约 10 万个 AS 拼接而成，每个 AS 就是一张"网络营业执照"—— 一家运营商(如中国电信、AT&T、谷歌)独立管理着自己的一块 IP 地址和路由策略。 怎么读？ 从圆心向外：最内圈是中国区整体 8,624 个 AS；第二圈拆成大陆(CN)/中国香港(HK)/ 中国台湾(TW)/中国澳门(MO)；最外圈按业务类型进一步细分——"ISP"基础运营商、"Eyeball"面向用户的接入网、 "Content/CDN"内容分发云商、"Government"政府专网等。 能看出什么？ 大陆独占 6,660 个 AS(77%)，但其中超过一半被归入"Other"， 这是因为国际公开目录对中国大陆本土小型企业专网的覆盖不全；换言之，我们"看得见"的中国大陆互联网 只是冰山一角，真正规模远大于图中所示。

大陆 / 中国香港 / 中国台湾 / 中国澳门各有多少 AS？

② 区域 AS 规模对比 · Bar

图解 大陆 / 中国香港 / 中国台湾 / 中国澳门各有多少 AS？
这是什么图？ 四个柱子分别显示大陆、中国香港、中国台湾、中国澳门拥有的 AS 数量。每个 AS 相当于互联网版图上的一块"行政区"。 数字告诉我们什么？ 大陆 6,660、中国香港 1,468、中国台湾 474、中国澳门 22。 中国香港面积仅 1,100 平方公里、人口七百多万，却拥有 1,468 个 AS——这看似矛盾， 实际是因为中国香港是亚太最重要的"互联网中立区"之一：众多跨国公司、CDN、云服务商把亚太分部的 网络注册地放在中国香港，利用其低延迟的国际带宽枢纽地位。 中国澳门为何只有 22 ？ 因为中国澳门本地互联网几乎完全依附内地或中国香港的骨干网， 没有发展出独立的运营商生态。这张图提醒我们：AS 数量不仅反映人口和经济规模， 更反映一个地区在全球互联网基础设施中的"中转"角色。

这些 AS 各自在经营什么业务？

③ 区域 × 标签类别 · Table

图解 这些 AS 各自在经营什么业务？
这是什么表？ 表格把每个区域的 AS 按业务类型横向切开。 各类别是什么？ "ISP" 是卖宽带的基础运营商；"Eyeball" 指用户接入网(如手机运营商)； "Content/CDN" 是加速网站的云厂商(阿里云、Cloudflare 之类)；"Academic" 是高校科研网； "Government" 是政府专网。 数据特点？ 大陆 ISP 931 个、Content/CDN 78 个、政府 17 个，这些数字看似偏低， 原因是国际公开目录(PeeringDB、CAIDA)对中国大陆本土运营商的归类覆盖不全，导致 5,118 个大陆 AS 被打上"Other"标签。这个现象叫"AS 归类黑洞"——国际视角能看到中国大陆的"骨架"， 但看不清细节的"毛细血管"。这张表是后续 19 步分析的起点，也是评估"主权指数"必须正视的 数据透明度问题。
